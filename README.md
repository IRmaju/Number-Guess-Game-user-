🤖🔢 Number Guessing Game 

## 🎮 About the Game

This is a **fun and interactive number guessing game** where:

> 🧠 **YOU** think of a number,  
> 💻 and the **Computer tries to guess it!**

Built using **Python** and **Streamlit**, the app lets you guide the computer by giving feedback:
- 🔺 "Higher"
- 🔻 "Lower"
- ✅ "Correct"
